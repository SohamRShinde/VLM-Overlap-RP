## Prompt 3: abstract and introduction

```text
Write the abstract and the Introduction in paper.tex.

Abstract: use this text, changing only what LaTeX or length needs. Use no
citations in the abstract (an AAAI rule). Stay under about 200 words.

  Vision-language models answer from the image by default, but other signals
  can override it. Prior work found that a sparse set of late attention heads
  lets a prompt asking for an object's \emph{usual} colour override a
  recoloured image. We ask whether the same heads let a colour word
  \emph{written in the image}, a typographic attack, override what the object
  looks like. We hold the task, the objects and the circuit-discovery
  pipeline fixed and vary only where the competing signal comes from, in
  Qwen2.5-VL-3B and PaliGemma2-3B. Our pipeline re-discovers the published
  prior-override circuit exactly in both models. In both, the typographic
  circuit overlaps it partly (Jaccard \JPT{} and \pgJPT): above chance, but
  well below the prior circuit's agreement with itself. In Qwen the overlap
  is in selection, not in cause. Ablating the prior-override heads leaves the
  typographic attack intact. The attack instead runs through later heads that
  attend to the note and write its colour, and with no note attend to the
  recoloured object and write \emph{its} colour. A circuit found by varying
  only the image overlaps the typographic circuit more than the prior circuit
  does (\JVT{} vs \JPT). In PaliGemma the causal separation is partial and
  depends on the ablation type. In-image text appears to exploit a pathway
  that moves colour from the image to the answer, not the circuit that lets
  prompted knowledge override vision.

Introduction: port the old draft's Introduction (draft_old.tex) with these
changes:
- Cite with \citet / \citep.
- Paragraph 4 ("We test this directly..."): name both models,
  Qwen2.5-VL-3B \citep{bai2025qwen25vl} and PaliGemma2-3B, and the three
  contrasts: P (prompted prior), T (typographic), and V (image-varying, from
  Lietzow et al.'s appendix), which controls for T varying the image.
- Contributions list, four items, no \S refs:
  (1) the answer-matched P/T/V design, with a pipeline that re-discovers
  Lietzow et al.'s circuits exactly in both models;
  (2) circuit overlap read against a chance floor and a split-half ceiling
  fixed before the T results existed: partly shared in both models, and the
  image-varying circuit V lies inside T;
  (3) cross-ablation against layer-matched random heads: on Qwen the shared
  heads are necessary for P only; on PaliGemma the separation is partial;
  (4) a mechanism for Qwen's T-only heads: they read the note and write its
  colour, and do the same with the object's colour when there is no note.
- Keep the sentence about pre-registration, and say the decision log will be
  released with the code. Give no URL.
- Remove the old \todo about citing the repo.
```

## After Prism (local, before submission)

1. Download `paper.tex` and `refs.bib` from Prism into `paper/`.
2. Run the tests. They now check every `.tex` in `paper/`: every
   result-shaped macro must be defined in `numbers.tex`, and no percentage
   may be typed.

   ```bash
   .venv/bin/python -m pytest tests/test_paper.py -v
   ```

3. Swap each `\figplaceholder{...}` for
   `\includegraphics[width=0.9\columnwidth]{figures/NAME}`, or
   `0.9\textwidth` in a `figure*`, then delete the `\figplaceholder` and
   `\todo` definitions.
4. Inline the numbers by script. This writes `paper/paper_flat.tex`, which
   is the single file to submit. The script refuses if `paper.tex` redefines
   a generated macro or has any other `\input`.

   ```bash
   .venv/bin/python scripts/flatten_paper.py paper/paper.tex
   ```

5. If a result changes later, re-run `scripts/paper_numbers.py`, re-upload
   `numbers.tex` to Prism, and flatten again. Nothing in `paper.tex` needs
   editing.
